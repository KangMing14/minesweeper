# Competitive Minesweeper

A browser-based competitive Minesweeper: 1v1 races on an identical seeded board, plus solo time-attack with leaderboards. TypeScript, pnpm monorepo.

**Status:** M0 Foundations in progress. See [ROADMAP.md](ROADMAP.md) once it exists (created in M0-T05).

This README is a stub. Setup, scripts and badges are added in M0-T04 and M0-T05.
