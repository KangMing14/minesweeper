## Decisions and deviations

- ADRs written or updated: none. No open decision settled. No dependency added.
- Choices the task left open, all recorded in `ARCHITECTURE.md`, "Results and scoring", under "Choices" and easy to change: (1) `effectiveCommands` is the length of the log, flags included; (2) `threeBV` is the plain board value and counts the free opening; (3) `computeThreeBV` is internal, though the task text names it and the canonical table does not list it; (4) `GameResult` fields are `readonly`; (5) the record covers finished games only, although the task objective says "finished or abandoned".
- `timeMs` is 0 and `threeBVPerSecond` is 0 for a game that the opening cleared at creation (M2-T03), and for a win by a command at `t = 0`.
- `threeBVPerSecond` is `threeBV * 1000 / timeMs`, one division, so it is the same on every platform.
