## Verification

- Before the change, on the untouched snapshot: `pnpm install --frozen-lockfile`; `pnpm typecheck`, `pnpm lint`, `pnpm format:check`, `pnpm check:todos` exit 0; `pnpm test` 786 tests in 30 files.
- Red first, for each of the six new modules: the test file failed to load (`Failed to resolve import "./<module>.js"`), 0 tests ran. Then the implementation. Test bugs of mine found by the first runs, fixed in the tests and not in the code: a wrong-flag check that compared coordinates of ops that carry none, and a "redrawn cells" check that compared x of glyph parts (both rewritten to assert by cell square); a scratch dataset with 52 cells for a 9x9 board was rejected by the renderer's own validation. One finding in the code: `BoardCanvas` rendered the first view twice on mount (once in the mount effect, once in the view effect); the first was removed.
- Mutation check by hand (not committed), each change restored and compared byte for byte: redraw every cell each time (8 tests failed), `hitTest` scaled by `devicePixelRatio` only (1), a click in a gap goes to the cell before it (26, later 10 after the check was rewritten), theme not read again on resize (1), a wrong flag drawn as a flag (4), no window resize listener (1).
- Real pixels: the renderer was run once in a scratch test against `@napi-rs/canvas` (installed outside the repository, not a dependency) at dpr 2 in light and dark, in play, lost and won states, and the PNGs were looked at. The first renders looked wrong only because the scratch harness left the gaps transparent; the page background was then composited behind, as the browser does. Numbers, flags, mines and the wrong-flag cross are distinct shapes in both themes. The scratch files are not in the repository.
- Budget: measured 2,029 canvas calls (4.2 per cell) and about 1.6 ms for a full redraw of a busy expert view with the fake context; the committed budget is 8 per cell, 25 for a one-cell change and 50 ms. The first draft (30 per cell, 100 ms) was too loose to catch a regression and was tightened.
